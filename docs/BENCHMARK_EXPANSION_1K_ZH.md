## 构造与验收

1. 排除原版源图及当前四机正式训练的冻结 reservoir；检查源图字节哈希，防止异名重复。
2. 为候选制作清晰原图和独立 mask 裁剪；写完指令后再看全图定位图，核对左右、前后、序数和重复实例。裁剪用于判断语义与 mask 范围，全图用于消歧。排序仅辅助找目标，并限制单一类别占满候选表；不根据类别标签直接判断通过。
3. 可用本地 VLM 预拟目标和指令，输出只能是待审核提议。审核者必须实际查看源图、对应 mask 和指令，并逐图记下接受、保留或拒绝的依据。
4. 不接受同一个人的不同部位、同一车辆的不同零件冒充不同父对象；独立携带的包可以独立计数。
5. 保留原始 RLE 解码后的 mask 像素；box 使用紧致半开边界，point 使用距边界最远的内部像素。检查不同目标重叠、图片与 mask 尺寸、文件哈希、源图唯一性及已有 instruction 协议。
6. 按场景写自然的精简单句。add 优先直接承载或附着，语义明确时省略重复部位：例如 `Add a chrome roof rack to the white vintage car on the right.` 不再重复说明车顶位置。
7. 总数达到 1,000 张且全部通过后，才进行正式发布验收；模型提议、待补查、失败样本一律不计入。

本次审核类型是 **assistant 直接视觉检查**，不是独立人工复核；也不代表下游模型已经完成编辑任务。

## 复现与续跑

在 benchmark repo 根目录执行：

```bash
# 核验/恢复全部冻结的视觉审核记录及显式修订；源图或审核图变化会报错。
python3 construction/expansion_reviews/record_batch001.py --all

# 续跑时按尚未准备的 records() 下标准备候选卡；prepare 只生成候选，不会接受样本。

OMP_NUM_THREADS=8 OPENBLAS_NUM_THREADS=8 MKL_NUM_THREADS=8 \
  python3 construction/expand_reviewed_v2.py build
```
