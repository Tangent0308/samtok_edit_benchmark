# CompBench 全量五方法评测结果

本报告合并四机正式结果与用户授权的 GPT 429 补判层。原始运行包、图像、评分记录和原始报告均保持不变。

## 范围与计分口径

- 每方法 3,481 条编辑请求，共五个方法、17,405 张输出；包含 2,905 条单轮请求和 288 条两轮序列（576 条请求）。
- 3,285 条请求采用官方客观指标；196 条动作／位置／视角请求采用已确认的论文 v2 提示词及 GPT-5.4。三类 GPT 分数单独报告，不与客观指标混成一个总分。
- 全部方法使用冻结配置、seed 42 和约 1MP 画布。连续编辑第二轮使用同一方法第一轮的实际输出。
- LC-T 衡量编辑局部与目标文字的一致性，LC-I 衡量编辑局部与目标图像的一致性，两者均采用官方 mask 外接框裁剪；PSNR、SSIM、LPIPS 按官方实现比较遮去编辑区域后的输出与源图。LPIPS 越低越好，其余越高越好。
- 按官方分组对下属子任务均值等权汇总；显示未提前舍入均值的三位小数。加粗为该列最高点估计（LPIPS 为最低），不表示统计显著性。

## 结果分析

1. **相对基座的客观指标改善广泛。** SITEdit 在五个客观评测分组、共 25 个指标中，有 24 项均值优于 Qwen-Image-2.1。这是本次全量集合上的点估计比较，不作为置信区间或显著性检验。
2. **隐式推理编辑表现突出。** SITEdit 的 LC-T 为 20.242（基座 18.237），LC-I 为 0.886（基座 0.807），五项指标均为本次五方法中的最优点估计。
3. **连续编辑第二轮更好地保持背景。** 相对基座，SITEdit 的 PSNR 从 18.458 提高到 24.795 dB，SSIM 从 0.508 提高到 0.895，LPIPS 从 0.276 降到 0.093（降低 66.2%）。第二轮继续使用各方法自己的第一轮输出。
4. **方法之间存在能力取舍。** 局部编辑中 SITEdit 的区域图像一致性和三项背景保真指标领先；多目标编辑中 RePlan 的区域图像一致性和背景保真更强，MICE 的 LC-T 更高。SITEdit 的多目标 LPIPS 高于基座，这一项没有延续其余客观指标的提升。
5. **动作、位置、视角应独立分析。** 这些是改变姿态、布局或视角的任务，不能只根据背景保真指标推断其完成情况。下列补判后 GPT 分数反映各方法在同一组完整请求上的实际表现：

- 动作编辑：SITEdit 4.303，Qwen-Image-2.1 6.404；本次最高为 FLUX.2 Klein-9B 6.742。
- 位置编辑：SITEdit 2.877，Qwen-Image-2.1 5.288；本次最高为 Qwen-Image-2.1 5.288。
- 视角编辑：SITEdit 1.912，Qwen-Image-2.1 5.059；本次最高为 FLUX.2 Klein-9B 5.647。

以上是各类任务的观测结果；区域化编辑更适合局部保真的解释仍是机制假设，不能据此单独归因于定位模块、区域码或训练。
