# Benchmark 与训练统一协议修复核查（2026-10-13）

本记录对应历史原版 release **2.4.0** 的数据标注、构造器、训练协议及方法文档修复。当前完整发布为 2.5.0（1,084 张源图、3,872 个目标），见主说明；下文迁移检查的范围是原版 200 张源图、785 个独立目标。原版分布：add 196、replace 196、remove 197、attribute 196。几何、实例绑定、编辑类别和正式交互分配与 2.3.0 逐项一致。

## 统一规范与实质修复

规范正文见 [统一 instruction 与源区域协议](INSTRUCTION_PROTOCOL_ZH.md)。两个仓库共用相同英文渲染代码、写作规范和中文协议正文。序列化版本 1.0、mask 含义 1.1、风格 benchmark-concise-2-direct-add-1 分别标记同一协议的三个方面。

全部 196 条 add 已显式保存新增物 payload、附着 relation、必要的宿主内 site；全部采用直接锚点。原 14 条被 near/below/above 词面误分为 reference 的任务已改为真实附着关系；不再扫描介词猜测锚点。锚点是源图中已有的承载/附着对象，不是新物体的结果轮廓。协议仍允许仅在直接添加不自然时使用紧邻、唯一、有支撑面的例外；当前 benchmark 没有使用该例外。

Ref / No-ref 从相同结构渲染，动作、物品、数量、属性、子部件和安装位置保持等价。指代优先一个最短且无歧义的名词短语，不另起位置补充句。中文、完成标准和 edit contract 随作者记录同步。

## 检查范围与结果

- 全量 785 组 Ref/No-ref 做结构一致性检查；196 个 add 均为 support。源图、mask、box、point、parent 实例和交互形式与旧版逐项比对。
- Qwen3.8-27B 对 785 条迁移初稿检查干净全图、局部图、二值 mask 和隔离区域，标出 37 条疑点。assistant 逐张查看这 37 条原图和 mask，修订 32 条，保留 5 条误报；修订也覆盖受影响的关联指代。
- 模型存在明显误报：051/U1 安全帽颜色、071/U2 路灯序数、079/U3 肩带、112/U5 全局方位、138/U1 最右灯泡。未将模型意见直接当成真值。
- 最终 Ref 平均 16.63 词、中位 17 词、最长 27 词；No-ref 平均 9.75 词、中位 10 词、最长 18 词。必要的局部安装位置不为长度硬截断。
- 训练和 benchmark 协议代码、风格模块与中文正文逐字校验。训练新建 unit 携带相同 mask_semantics；子部件任务标记需要局部执行区域。字段一致不等于区域分割或生图质量自动合格。

这是全量自动核查加疑点目视复核，**不是独立人工验收，也不是 785 条全部经 assistant 再次逐图验收**。未新增 benchmark 编辑结果图，不声称已验证任意生成器的成功率。可视化展示源图、任务和输入；发布记录与浏览器检查分别留有回执。
