## 1. Benchmark、输入和指标

MagicBrush 是基于 COCO 图像、人工编辑指令和编辑 mask 构建的多轮图像编辑数据集，参考编辑结果由 DALL-E 2 辅助产生。本次使用官方 test：**535 个会话、1,053 个编辑轮次**；一／二／三轮会话分别为 216／120／199。官方数据与评测代码采用 CC BY 4.0，原始 COCO 图像保留来源权利。数据从官方仓库和 Hugging Face 下载固定版本，原始下载隔离存放，SOURCE 记录版本、许可和哈希，未执行数据包中的代码。

| 轨道 | 独立单轮（single-turn） | 连续多轮（multi-turn） |
|---|---|---|
| 无 mask | 每轮使用该轮官方 source 和原始指令；评价全部 1,053 轮 | 从会话原图开始，每轮使用本方法上轮输出；评价 535 个会话最终图 |
| 提供 mask | 同上，额外提供本轮官方公开 mask | 同上，提供本轮 mask；不根据生成结果重新定位或修 mask |

独立模式的第 2/3 轮使用数据集提供的上一轮参考图；连续模式使用本方法上轮输出，二者分开统计。第一轮精确复用，每轨道每方法为 `1053 + 518 = 1571` 个唯一生成请求，两轨道合计 3,142 个。连续评分只取最终轮，不能把全部连续生成请求数当作评分分母。

所有方法使用相同约 1MP、1024×1024 公开网格，保留 raw 与恢复后的 output，seed 42、每请求只采样一次。公开 mask 由原始 alpha<128 确定性转换；不读取 GT 差异、不调用外部 SAM 或定位器。GT、local/global descriptions 只进入评分和展示，不能送入编辑模型。

| 方法 | 无 mask 的输入与原生流程 | 提供 mask 的输入与原生流程 | 主要冻结参数 |
|---|---|---|---|
| SITEdit | 原始指令 → Pass1 定位区域码 → S2 | 公开 mask → 原生 SAMTok codec 区域码 → S2，不调用 Pass1 | aa5a414；raw TE；40 步；γ=2；同句去 token 的负分支；Pass1 step 2000，S2 adapter_16000 |
| Qwen-Image-2.1 | 清图 + 原始指令 | 清图 + mask 标记图 + 固定角色说明 + 原文 | 40 步，CFG 1，KV cache，原生 CPU offload |
| Qwen-Image-Edit-2511 | 清图 + 原始指令 | 同上 | 40 步，true CFG 4，guidance 1，单空格负向 |
| RePlan | 原生 planner → Qwen2511 editor | planner 看标记图；editor 编辑清图 | 40 步，CFG 4，expand 0，attention switch .5 |
| MIRAGE | 原生 parser / locator → 联合编辑 | locator 看标记图；editor 编辑清图 | 40 步，CFG 4，原生 patch ratio .4，padding 10 |
| FLUX.3 Klein | 带原生图像引用的原文 + 清图 | 清图与标记图按固定角色分别引用 | 16 步，PUP 关闭，boxes=None |

SITEdit 全部 3,142 条区域码记录与 S2 依赖已核对，没有无效区域码导致的纯文本回退。无 mask 的 Pass1 调用 1,571 次，有 mask 的 codec 编码 1,571 次；另有 3,142 次诊断性 codec 解码，不作为额外定位输入。1,366 条使用冻结的通用句尾插入规则 `fallback_end`，这是 token 放置规则，不是生成失败。未使用 LoRA 强度调整、quality-anchor 或 v5 变体。

本次“评分”是免费、确定性的标准特征指标，**不是 GPT/VLM Judge**：

| 指标 | 含义与方向 |
|---|---|
| L1 ↓ | RGB [0,1] 上输出与参考图的平均绝对像素误差 |
| L2 ↓ | 均方像素误差 MSE，不开根号 |
| CLIP-I ↑ | 输出和参考图的 CLIP ViT-B/32 图像特征余弦 |
| DINO ↑ | 输出和参考图的原版 DINO ViT-S/16 CLS 特征余弦 |
| CLIP-T ↑ | 输出图与官方 local description 的 CLIP ViT-B/32 余弦 |

主要协议差异：生成统一约 1MP；有 mask 轨道也使用现行公开 scorer 的整图五指标，而 MagicBrush 论文 Table 3 使用区域指标；CLIP/DINO 使用固定发布者转换权重、FP32/eager 实现，DINO 恢复原版 epsilon=1e-6 并经原权重／独立前向核验；三条官方空 local description 原样保留；生成失败加入用户批准的额外惩罚。因此本表只在本次重跑的八方法之间比较，不与论文历史数字直接合并排名。官方来源、权重版本、历史基线及全部偏差见 [冻结评测方案](MAGICBRUSH_EVALUATION.md)。

## 4. 结果分析：统计结论与解释分开

1. **统计结果：SITEdit 相对底座的优势集中在连续编辑的像素与图像特征一致性。** 全量无 mask 连续编辑中，SITEdit / Qwen-Image-2.1 的 L1 为 0.0973 / 0.1291、L2 为 0.0407 / 0.0474、CLIP-I 为 0.8823 / 0.8505、DINO 为 0.7925 / 0.7499；提供 mask 时对应为 0.0924 / 0.1104、0.0384 / 0.0395、0.8894 / 0.8558、0.8059 / 0.7711。共同去重合子集保留同样的四项方向。这里描述的是实测均值，不将其表述为所有指标全面领先；CLIP-T 与上述图像指标分开报告。
2. **统计结果：不同基线有不同侧重。** FLUX.3 在全量无 mask 的独立／连续两表均取得四项图像指标的最优点估计；提供 mask 后，MICE 在两表的 CLIP-I、DINO 上最高。Qwen2511 在无 mask 两表和有 mask 独立表的 CLIP-T 最高，FLUX.2 在有 mask 连续表的 CLIP-T 最高。SITEdit 的完整位置应由这五项分列结果表达，不构造未经约定的综合分数。
3. **统计结果：公开 mask 的收益依赖方法和指标。** SITEdit 从无 mask 到有 mask 时，四种图像指标在独立和连续两种模式下均改善；MICE 的 CLIP-I/DINO 也改善。Qwen2511 的有 mask 行在多项指标上低于其无 mask 行，说明同一公开 mask 通过通用标记图输入时，并不保证每个模型都能有效使用。当前比较包含各方法冻结的输入适配，不能把这一差异直接归因于某个单独模块。
4. **统计结果：去重合后主要方向仍然存在。** 例如 SITEdit 在去重合的无 mask 连续表 L1=0.0938、CLIP-I=0.8846、DINO=0.7980，Qwen-2.1 为 0.1262、0.8530、0.7583。该共同子集降低了已知源图重合的影响，但两套结果不能用来量化未知预训练数据的影响。
5. **统计解释：MIRAGE 主表同时反映成功输出质量与原生流程失败。** 540 条失败保留于完整请求集合，按各面板实际分母加入惩罚；因此其最终分数不能解释成“成功图像的平均质量”。原始报告另外保留成功输出的 `available_only_means`，仅供诊断，不用不一致的成功子集做主排名。
6. **待验证假设：** 区域码条件可能有助于控制连续编辑中的场景漂移；本实验只测完整冻结方法，不能据此单独确认区域码、定位器或训练监督的因果贡献。本轮不增加消融、不修改已冻结配置。
