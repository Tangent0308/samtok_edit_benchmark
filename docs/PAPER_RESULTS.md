## 1. 结论摘要

- 我方十种 setting 平均 **UnitPass 81.1%、JointPass 50.3%**。最强基线 Qwen-Image-2.1 为 64.0% / 29.4%，配对差 **+17.1 / +20.9 个百分点**，区间远离 0。相对其余基线，UP 高 34.5–48.0 个点，JP 高 34.4–44.1 个点。
- 我方在 **每个 setting** 上都显著好于每个基线。唯一不显著的是 **S2-box 对 Qwen-Image-2.1**：JP +1.2 [−2.6, +5.0]，UP +0.7 [−0.9, +2.4]。直接给框时，Qwen-Image-2.1 很强。
- 优势最大的是 no-ref 场景（S3、S4-noref）：指令不指名目标，只靠区域定位。对 Qwen-Image-2.1，S3-point JP 高 37.1 个点，S4-noref 高 34.3 个点。其余基线在这些 setting 上的 JP 都低于 5%，唯一例外是 MICE 的 S3-box/S3-mask（9.2%）。
- 我方在 no-ref 下随区域形式的波动最小：JP 形式鲁棒性 0.89，基线为 0.22–0.76。区域提示对我方三种形式都是显著的正增益（S2−S1：JP +3.9 至 +5.0）；多数基线给点或 mask 后反而比只给文字差。
- 目标越多越难。我方在 K=5 时 JP 仍有 21.2%，基线为 0.0–10.2%。

### 2.4 Judge 与指标

- **Judge**：`Qwen3.8-Flash-Next-FP8`，revision `236dfdf285828023ca3bcd3f37366c58a3469b13`，协议 `ifbench.canonical-epq.v1`。
  - 解码：temperature 0，seed 0，max_tokens 12288，reasoning_effort low。
  - 引擎：vLLM 0.31.0，TP8 + expert parallel，batch 16，max_model_len 49152。
  - 证据：全图最多 1024² 像素，局部裁剪最多 512² 像素，源图和输出画同一条 GT 轮廓。
  - 八个方法全部用同一个 Judge 和配置。Judge 只看原始源图、回到原尺寸的输出、canonical 指令和 GT selector，不知道方法名和 setting。
- **E/P/Q**：每个单元 0–4 分，分别为完成度、保持、质量；另有全局 P/Q。
- **UnitPass（UP）**：E=4 且 P≥3、Q≥3 的单元比例。每个方法×setting 的分母是 3,872 个单元。
- **JointPass（JP）**：同图全部单元通过，且全局 P、Q≥3 的源图比例。分母是 1,084 张源图。
- **十种平均**：十个 setting 的算术平均；其区间由同一组 bootstrap 抽样上的平均得到。
- **区间**：以源图为 cluster 的配对 bootstrap，10,000 次，seed 20261027，抽样索引表 SHA256 `7925cd19727a526308d70c1a693ad6b67ce07516c190516611b12d1edb607ca0`。八方法、十种 setting 共用这一张索引表。配对差值在同一次抽样上相减。K 分桶在各桶内按图另行抽样。
- **派生指标**（对 UP 和 JP 分别计算）：
  - 语言依赖 `M(S2-m)−M(S3-m)`；
  - 区域增益 `M(S2-m)−M(S1)`；
  - 形式鲁棒性 `min_m M(S3-m)/max_m M(S3-m)`；
  - 混合代价 `mean_m M(S3-m)−M(S4-noref)`。
  - 其中 m 取 point/box/mask。
