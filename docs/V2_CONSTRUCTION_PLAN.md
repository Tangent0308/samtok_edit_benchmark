# v2 多对象交互构建约束

v2 从新的源图及其原始分割标注构建，排除 v1 正式 450 条及其 433 条扩充候选使用的源图；不复用其任务、指令或已挑出的单目标。已知训练曝光与同场景重复另做排查。目标为至少 200 张独立源图，每条有 2–4 个不同物体的独立编辑单元。

每个物体可以编辑整体或部件。同一物体的分离可见块归入同一单元，不计为多个物体；整体与部件也不重复计数。每条任务需有实际可见的实例选择、部件范围、遮挡覆盖、细结构或邻接保护难点。

每个单元的 ref 指文本 referring expression。支持 ref-only、ref+mask、ref+box、ref+point、noref+mask、noref+box、noref+point；无 ref 时必须给区域，有 ref 时区域可选。noref 保留操作和必要的通用部件粒度，但不提供唯一实例描述。主集每条混合至少两种输入形式。

逐例查看干净原图、候选 mask 与上下文局部细节，记录具体保留/拒绝原因。原图必须清楚、单元可消歧、mask 语义与边界匹配、多个编辑要求可同时满足。不把元数据分数、原始 mask 数、baseline 失败或 SAMTok codec 的容易程度当成准入结论。

主指标沿用完成 E、保持 P、质量 Q，要求每个单元全部过关及全图保持/质量过关。逐单元输入与 evaluator 私有 mask 分开；point/box/ref-only 不允许泄漏 GT mask。独立人工审批与本轮 assistant 逐图审阅分开记录，不伪造人类审核。

素材和逐例审阅证据保存在仓库外的数据目录；Git 保存冻结任务、来源/哈希、审核记录、统计、代码和少量样例。本轮已冻结 212 张独立源图、540 个物体目标；最终数量与验证结果由 `data/v2/release.json`、`validation.json` 给出，详细结果见 `V2_REPORT_ZH.md`。
