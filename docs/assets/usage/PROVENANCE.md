# 文档插图来源

本目录只保存 11 张已有报告 JPEG 的逐字节副本：固定 case `v2-sa_607902` 的 Qwen2.1 十种 setting 对照，以及同例 MICE S2-mask 对照。选择由预先固定的 plan 首例决定，没有按分数挑图。未生成新图、未重编码、未裁剪或修改模型输出。

每张图的原始路径、输入/结果路径、SHA、缓存来源和 native binding 链接见 [PROVENANCE.json](PROVENANCE.json)。原始数据、全量输出、权重和评分继续保存在外部共享目录；文档副本不构成对源图、输出或第三方权重的再许可。

三列依次是清洁源图、实际视觉输入、实际输出。Qwen2.1 的 S1 实际只输入一张 I，中列只是重复显示 I；其余九例实际输入 I+A。MICE S2-mask 的视觉输入是清图 I，另外通过原生参数输入二值绑定；中列不是 mask，也不是彩色标注图。S1 的 Qwen 输出是已披露的 resident 精确缓存，其余九个 Qwen 示例为本轮 offload 新输出。
